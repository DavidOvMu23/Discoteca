The Entity Framework Core tools help with design-\/time development tasks. They\textquotesingle{}re primarily used to manage Migrations and to scaffold a {\ttfamily Db\+Context} and entity types by reverse engineering the schema of a database.

This package, {\ttfamily Microsoft.\+Entity\+Framework\+Core.\+Tools} is for Power\+Shell tooling that works in the Visual Studio Package Manager Console (PMC).\hypertarget{md__c_1_2_users_2_david_01_oviedo_2_desktop_2_viniloteca_2packages_2_microsoft_8_entity_framewor9ebd87aff5957e243b4fc75a87b660be_autotoc_md5}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{md__c_1_2_users_2_david_01_oviedo_2_desktop_2_viniloteca_2packages_2_microsoft_8_entity_framewor9ebd87aff5957e243b4fc75a87b660be_autotoc_md5}
Install the tools package by running the following in the Visual Studio PMC:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{Install-\/Package\ Microsoft.EntityFrameworkCore.Tools}

\end{DoxyCode}
